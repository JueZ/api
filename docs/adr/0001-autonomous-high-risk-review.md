# ADR 0001: Deterministic autonomous governance

- Status: superseded by ADR 0006
- Date: 2026-08-09

This ADR previously selected a protected custom controller and deterministic `Autonomous review complete` aggregate after removing paid model review. ADR 0006 removes that controller, its check-run writer, workflow hashes, arbitrary status rollup, and historical program-evidence coupling. Git history preserves the original decision.
