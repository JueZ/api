---
name: learning
description: Turn a significant or recurring observed failure into a focused regression and concise reusable project knowledge.
---

Confirm the causal evidence and scope. Add the smallest useful regression for a demonstrated failure; do not encode guesses or wording checks as behavioral proof. Treat repeated reports of one incident as one evidence lineage.

When the finding changes a durable decision, unresolved risk, or next action, update the existing project memory with the invariant, evidence reference, and applicability limit. Keep run history in its source system, omit secrets and raw logs, and retire stale guidance when counterevidence warrants it. A learning note grants no authority and proves no deployment or model improvement.
