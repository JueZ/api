# Portable agent operating contract

This source package provides operating guidance and unconfigured project adapters. It creates no service, CI gate, credentials, remote repository, or deployment permission. It needs Node.js 22; Git is used for local diagnostics. No model API is required.

From the source checkout, run `node scripts/export-agent-template.mjs <destination>` with one quoted destination path. The exporter copies only its explicit file list to a nonexistent or empty directory outside the source checkout. Any existing entry (including `.git`) or symbolic-link ancestor is rejected; nothing is overwritten. Export before initializing a new local repository, or review the exported files for manual integration into an existing project. An I/O failure may leave a partial new export; inspect it before choosing a fresh empty destination.

Bootstrap requires a project owner to bind the protected branch and required check names; native merge rules; secret store and least-privilege identities; allowed deployment/recovery commands and targets; time, repair, and spending budgets; and the accepted-release source with exact revision/digest, smoke, telemetry, and recovery evidence. Record only relevant bindings in `docs/architecture.md` and current decisions/risks in `docs/project-memory.md`. Unknown bindings stay unconfigured and do not authorize dependent operations.

Implement these three scripts as direct adapters to the project's existing tools. Invoke fixed executables with argument arrays; avoid shell evaluation or a new orchestration layer. They initially return JSON with `status: "unconfigured"`:

| Command (from the exported root)                                        | Project adapter contract                                                                                                                                                                                                                                                |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `node scripts/doctor.mjs`                                               | Read-only Node/Git diagnostics and configuration gaps. Exit 0 means diagnostics printed, never readiness.                                                                                                                                                               |
| `node scripts/validate-affected.mjs --base <sha> --head <sha> [--plan]` | Select checks from the exact diff including dirty inputs; record dependency/toolchain identity, per-step results/durations, and repeats. A plan is not a pass. Unknown/unconfigured exits 2; failed validation exits nonzero; only observed applicable checks can pass. |
| `node scripts/delivery-status.mjs --sha <sha>`                          | Read-only protected checks, merge, deployment, accepted release, and runtime evidence for the exact candidate. Unknown/unconfigured exits 2. Incomplete, blocked, failed, and superseded states remain nonzero; only proven applicable completion exits 0.              |

Reuse existing evidence locations instead of inventing timings or a second ledger. Never infer runtime success from local checks, merge, or supersession. Validate the bindings locally and then in the intended project's authorized workflow. Exports into local fixtures demonstrate packaging portability only; adoption in a second real repository requires choosing that repository and completing its bootstrap.
